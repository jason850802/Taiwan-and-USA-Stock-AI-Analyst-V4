# 02 — 回灌（覆蓋 ＋ 兩道防護 ＋ 重載）

**What to build:** 使用者在庫存頁按下「回灌」、選一個備份檔，App 先驗檔，
再用筆數對照的確認框問他「現有這些 → 要換成備份檔裡的這些（匯出於某時）」。
他按下確認的當下，App 先自動下載一份現況的**預備份**當救命索，才整包覆蓋
五把本體資料 key，然後整頁重新載入——畫面即為備份當下的樣子。

驗證不過的檔案一律整包拒收，現有資料**一個位元組都不動**。取消就是什麼都沒發生。

詞彙照 `CONTEXT.md`：叫「回灌」不叫匯入、不叫還原（「匯入」已被對帳單功能佔用）。
**覆蓋式是拍板決定**（`docs/adr/0001`）——不要自作主張加合併邏輯來「幫使用者省事」，
已實現帳本與每日快照沒有去重鍵，合併會把同一筆賣出的損益算兩次且畫面沒有任何徵兆。

**Blocked by:** 01 — 備份下載（預備份直接複用 01 建好的備份與下載程序）

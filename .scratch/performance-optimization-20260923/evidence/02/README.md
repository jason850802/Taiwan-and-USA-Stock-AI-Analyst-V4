## 摘要檔命名

- runner 產出的 run：`summary-<判定器雜湊>.json／.md`；對等比對：`parity-summary-<工具雜湊>-<判定器雜湊>.json`；重載驗證：`reload-summary-<工具雜湊>-<判定器雜湊>.json`；收益比較：檔名帶候選與基準 run 及判定器雜湊。
- 同版重播只比對、不覆寫；工具或判定器修改後另寫一份，舊版保留。以本票提交的工具重播任一正式 run，應得到與同雜湊摘要逐字相同的結果。

# 06 — 補完整正式 App 與本體資料驗收

Status: ready-for-agent
Blocked by: 05
Type: task

## 要交付的證據

正式 App 的實際入口、桌面與窄版都使用候選，所有操作資料正確；補上上輪缺的每操作五鍵原始字串與預期變更對帳。

## 工作

- 全新 origin、合成持股、假 AI、可見面板。尺寸固定桌面 1280×720、窄版 375×812，不接觸真帳本 origin。
- 原生操作搜尋、台／美五週期、暖回訪、強制更新、十檔庫存、移除／重加、合成快照、健檢失效；量到畫面，保存 errors 與 request trace。
- 每步保存五鍵 before／after 原始字串。只讀步驟全相同；合成寫入步驟依預先定義的 fixture delta 驗允許鍵，其餘不變。
- 核對本案變動不破壞 P1 證據身分、S1 輸入簽章、存檔後失效及手動重跑規則。
- 頁面前後來源、listener PID、工具及快取模式可驗；中途面板背景則留失敗，不覆蓋。

## 驗收

- [ ] 桌面／窄版每個步驟都有 raw 五鍵字串及明確預期差異，無只列鍵名或 boolean 的缺口。
- [ ] 所有圖表／報價／FX／狀態與固定資料吻合，無 stale UI／stale cache，無真 AI。
- [ ] 0 個非預期 console error／unhandled，預期失敗獨立列出。
- [ ] 日常入口與正式服務身分相符，畫面時間以可見面板取得。
- [ ] 舊案合成 App 五鍵缺口有新證據可補，舊 raw 原樣保留。
- [ ] 工具與文件獨立覆核、必要 gate 及精確提交完成。未通過不得進大批真行情。

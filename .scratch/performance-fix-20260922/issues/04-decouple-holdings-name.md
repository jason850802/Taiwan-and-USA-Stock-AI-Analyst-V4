## 要交付的結果

Yahoo 有效價格到達後立即可見並釋放價格工作；中文名稱可稍後補齊。名稱慢、失敗或逾時不使有效價格失敗，也不能覆蓋更新一輪的價格或狀態。

## 實作範圍

- 盤點最新價呼叫端、名稱來源與名錄快取，選相容的內部接縫；維持現有最新價結果契約及非本票呼叫端。
- 名稱工作獨立去重但仍受同一庫存有限 HTTP 排程約束；價格與匯率優先，三槽先保持不變。
- 名稱補入只 patch 對應名稱；UI 與服務快取都要核對請求身分／世代，舊名稱不能帶回舊價格、交易日或錯誤。
- 固定時鐘驗證 `fetchedAt` 採樣與沿用窗；名稱晚到不能刷新報價時間。
- 不回寫持股名稱或本體資料，不因名稱補入觸發 AI 或讓既有健檢變成需重檢。

- [x] 01 的名稱 pending 紅燈變綠，且後續價格工作在名稱未完成時可起跑。

- [x] 新價先到舊名稱後到、移除／重加、卸載、快取回讀與跨沿用窗均不污染新狀態。

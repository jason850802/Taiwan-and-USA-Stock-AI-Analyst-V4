## 目標

賣出視窗長出當沖勾選框：預設值＝自動判定結果、可覆寫、硬閘停用、附理由文字；
勾選狀態傳進引擎，預覽與入帳同一條路。

## 規格依據

spec.md「UI（賣出視窗）」節＋硬閘／軟閘表；CONTEXT.md「台股現股當沖」節
（文案用詞不得漂移出詞彙表）。

## 範圍

做：
- 台股個股：顯示「現股當沖（證交稅減半 0.15%）」勾選框，預設＝`assessDayTrade`
  結果；理由文字由 reason 代碼映射。
- 台股 ETF／債券 ETF：勾選框**顯示但停用**＋說明。美股：**完全不顯示**任何當沖控制項。
- `odd-lot-sell`：停用＋提示拆兩筆。
- 覆寫黏性：使用者手動改過勾選後，**任何股數或日期變動即重置回自動判定**
  （沿買入表單費用欄的 touched 模式）。
- 勾選時預覽的證交稅列標示「（當沖 0.15%）」。
- UI **直接呼叫 `assessDayTrade`** 畫框與理由（不依賴預覽是否成立；價格空白時
  框照常運作）；預覽與確認把勾選框當下值傳給引擎。

建議文案（語氣可微調，語意不可變）：
- eligible：「符合現股當沖：本批買進日＝賣出日、整張交易」
- etf-not-eligible：「ETF 當沖不適用減半，證交稅仍 0.1%／債券 ETF 免稅」
- odd-lot-sell：「零股不得當沖；若實為整張當沖＋零股賣出，請拆成兩筆賣出」
- odd-lot-holding：「本批持有含零股，未自動認定；當日整張買賣屬實可手動勾選」
- date-mismatch：「本批買進日 {日期} ≠ 賣出日」
- no-buy-date：「本批未記買進日；確為當沖可手動勾選」

不做：
- 帳本顯示（票 04）。
- 任何引擎、費稅邏輯變動。

## 驗收

- `npm run gate` 全綠（UI 票也全跑）。
- 起 preview 以 **DOM 驗證**（不靠截圖，截圖會逾時）走五情境，測試資料用乾淨代號
  建立、驗後清除：
  1. 今日買進的整張個股測試批（如 1000 股 × 賣價 650）→ 開賣出視窗**預設勾起**、
     理由正確、預覽稅＝**975**（手算減半值）。
  2. 舊買進日個股 → 預設不勾、理由 date-mismatch；手動勾起（軟閘）→ 稅變減半。
  3. 在今日批上手動取消勾選（覆寫 false）→ 改股數 → 框**回到自動勾起**（覆寫重置）；
     改賣出股數 1500 → 框**停用**＋拆兩筆提示、稅回一般（硬閘）。
  4. 一般 ETF → 框停用＋說明、稅仍 0.1%。
  5. 美股 → 無任何當沖控制項。
- console 零紅字。
- DOM 驗證完成後停掉 preview 再做 git 操作（Windows 檔案監看鎖 git 的既有教訓）。

# 01 — 費稅純函式支援當沖減半稅率

Status: ready-for-agent
Blocked by: —（首票）

## 目標

費率設定檔新增當沖個股稅率 `0.0015`；費稅模組的「稅率查詢」與「賣出費稅計算」
各加一個 optional 的 `isDayTrade` 參數，預設維持現行為。本票結束時所有既有呼叫端
行為 bit-for-bit 不變。

## 規格依據

spec.md「費率與算稅」節；ADR-0003 決策 3（只有個股減半）。

## 範圍

做：
- 費率設定檔：當沖個股稅率常數 `0.0015`，與三檔一般稅率並列（計算式與 rounding
  不搬進設定檔——沿該檔「設定與計算分離」原則）。
- 稅率查詢函式：optional `isDayTrade` 參數；個股＋`true` → `0.0015`；
  `etf`／`bond-etf` **一律忽略旗標**（縱深防禦最底層）。
- 賣出費稅計算：optional `isDayTrade` 參數，透傳給稅率查詢。
  正典公式 `floor(value × 稅率)`，**單次 floor、禁止中間 rounding**。
  手續費完全不受旗標影響。

不做：
- 任何呼叫端的改動（判定與引擎整合是票 02）。
- 手續費率、rounding 規則的任何變動。

## 驗收

- 新增測試案例（**既有案例零修改**）：
  - 稅率查詢：個股＋`true`＝`0.0015`；個股＋`false`／缺參＝`0.003`；
    ETF＋`true` 仍 `0.001`；債券 ETF＋`true` 仍 `0`。
  - 賣出費稅手算對數（先手算再寫斷言）：
    - 650,000 當沖 → 稅 **975**（一般 1,950）、費仍 **926**；
    - 321,500 當沖 → 稅 **482**（482.25 floor；一般 964）；
    - 500 當沖 → 稅 **0**（0.75 floor；一般 1）、費仍 **1**（max(1,·)，鎖「旗標恆不影響手續費」）。
  - 同金額缺參結果＝現行行為（回歸鎖）。
- `npm run gate` 全綠。

# 步驟 2／7：當下位置（Position）

確認趨勢為多頭後，判斷股價在波段中的位置——位置決定風險報酬比。

## 資料來源
沿用本次對話的 `fetch_stock.py` JSON（未抓過才執行 `python .claude/skills/_shared/fetch_stock.py <股號>`）。
讀取 `daily.swings`、`daily.latest`（close、ma 系列）、`daily.retrace`（回檔 1/2 法則欄位）、`daily.position_anchors`（高檔量化錨點）、`daily.key_levels`（大量紅黑K與缺口支撐壓力）。

## 判定規則（六六大順②／朱家泓波段位置與進階第五章淘汰法）
多頭分段：**打底 → 初升段 → 主升段 → 末升段**；行進狀態：起漲 / 上漲中 / 短線高檔 / 回檔 / 遇壓 / 止跌 / 遇支撐 / 突破。

判讀要點：
1. **最佳進場位置**：
   - **打底剛突破 / 初升段起漲**：✅ 最佳波段起點。
   - **主升段弱勢回檔遇支撐**（回檔 < 1/2、不破前低、守月線 MA20 / 向上缺口 / 大量紅K支撐）：✅ 符合「回後買上漲」或「強勢飆股第二波選股法」（進階 p.412）。
2. **回檔深度 1/2 法則**（初階 CH2 p.74-75，看 `daily.retrace`）：
   - **弱勢回檔**＝回檔幅度 < 前波漲幅 1/2（`ratio < 0.5`）且不破月線（`below_ma20=false`）、未破前低（`broke_prev_low=false`）→ 多頭續漲，「回後買上漲」正宗場景 ✅。
   - **強勢回檔**＝回檔超過 1/2（`ratio > 0.5`）或跌破月線 → 易進入頭頭低盤整，必須觀察股價再站回月線且符合多頭架構後再做多 ⚠️（戒律 4）。
   - **跌破前低**（`broke_prev_low=true`）且步驟 1 日線已非多頭 → 趨勢已破壞轉盤整，再上漲屬**逃命波** ❌（觸犯戒律 5，不可做多）；若 ABC 回檔收斂後日線仍判多頭，只列 ⚠️ 警示。
3. **末升段 / 高檔量化錨點**（看 `daily.position_anchors`，對應進階連三紅 p.48-51 與淘汰法）：
   - `rise_from_major_low_pct ≥ 100`：自波段大底起漲**達一倍＝高檔位置**（進階 p.51、淘汰法 #5）→ ⚠️ 若出現急漲連三紅爆量或頭頭低盤整，嚴禁追多、準備出場。
   - `ma5_run_rise_pct > 20`：沿 5 日均線累計漲幅**超過 20%**，遇大量長紅後變盤訊號 → ⚠️ 停利警戒（進階 p.51）。
   - `up_streak ≥ 3`：連漲 3 根以上勿追高（戒律 2）。
   - 離 MA20 正乖離過大亦屬短線高檔 → ⚠️ 追高風險（葛蘭碧賣訊 4、戒律 8）。
4. **進階班「淘汰法選股」位置過濾**（進階 CH5-3 p.360-380）：
   - 向上遇到前高重壓或上方未回補向下缺口（`open_gaps_down`）、且壓力區附近多次出現大量長黑 K（淘汰法 #2、#6）→ ❌ 避開。
   - 上有重壓、下有支撐的狹幅區間震盪（淘汰法 #3、戒律 6）→ ❌ 等突破再進。

## 輸出格式
```
【步驟2 當下位置】
狀態：✅佳 / ⚠️追高或強勢回檔警戒 / ❌不宜(高檔鈍化末端/破前低逃命波/重壓區)
波段位置：<打底/初升/主升/末升段>＋<起漲/弱勢回檔/強勢回檔/高檔…>
回檔與高檔錨點：前波回檔比 <ratio>（弱勢<0.5/強勢>0.5）；距波段低點漲幅 <rise_from_major_low_pct>%；連漲 <up_streak> 日
與均線/支撐壓力關係：close 對 MA10/MA20 位置、上方壓力與下方支撐
結論：<進場位置是否理想>
```
接著提示可進行 **步驟3 kline-signal**。

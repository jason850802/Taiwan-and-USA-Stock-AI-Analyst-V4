# 步驟 1／7：趨勢研判（Trend）

判定個股趨勢方向，這是進場的第一道關卡。**盤整一律退出觀察**，不做多。

## 資料來源
執行：`python .claude/skills/_shared/fetch_stock.py <股號>`
（若本次對話已抓過同一股票，直接沿用先前 JSON，**勿重複抓取**。）

讀取 `daily.trend`、`daily.trend_reason`、`daily.swings`、`daily.pending_swing`、`weekly.trend`、`daily.latest`、`weekly_resistance`（週線壓力價與距離%）。

## 判定規則（朱家泓初階 CH2／道氏理論與 MA5 轉折波）
1. **短線轉折波取點原則**（初階 p.17-24）：
   - **突破 5 均取低點（含下影線）為「底」；跌破 5 均取高點（含上影線）為「頭」**。
   - 搭配 `pending_swing` 觀察當前尚未完成轉折的暫時高點／暫時低點。
2. **多頭** = 頭頭高 + 底底高（兩個條件必須同時成立，缺一不可）→ 順勢做多。
3. **空頭** = 頭頭低 + 底底低 → 不做多。
4. **盤整與趨勢改變的先知先覺**（初階 p.33-36、p.56-59）：
   - **多頭回檔跌破前低**（出現底底低）→ 趨勢轉為盤整，之後再上漲稱為**「逃命波」**（觸犯戒律 5，不可做多；若再跌破新低即空頭確認）。
   - **多頭上漲未過前高就下跌**（出現頭頭低）→ 趨勢轉為盤整（退出觀察，等突破上頸線或跌破下頸線）。
   - **空頭改變先知先覺**：空頭反彈突破前高（出現頭頭高）或回檔不破前低（出現底底高，黃金右腳）→ 進入底部盤整鎖股觀察；若**空轉多且再次突破空頭最後高點（空轉多過空高要大漲，進階 p.85 祕笈5）**則為強勢翻多訊號。
5. **日線 vs 週線**：兩者皆多頭最佳；若週線空頭、日線多頭，視為空頭反彈，列警示（對應做多戒律 7）。
6. **週線壓力空間**（看 `weekly_resistance`）：現價上方最近週線轉折高＝壓力價；`distance_pct < 5%` → 遇週線壓力前勿做多（戒律 3）；為 null 表示創新高無上方壓力。

## 輸出格式
```
【步驟1 趨勢研判】
狀態：✅多頭 / ⚠️多頭但與週線背離 / ❌空頭或盤整
日線：<多/空/盤>（理由：<trend_reason>）
週線：<多/空/盤>；週線壓力：<價位>（距 <x>%）/ 無（創新高）
最近轉折：列出最後 2 高 2 低（日期+含影線價位）＋當前暫時高低點(pending_swing)
結論：<是否進入下一步>
```

- 若日線非多頭 → 明確標示「不符合做多前提，流程可中止（轉入步驟7鎖股觀察）」。
- 接著提示使用者可進行 **步驟2 position-analysis**。
